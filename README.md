# 👨🏽‍🌾 Agri-X

Um pequeno sistema de autenticação de usuário, onde o usuário pode realizar cadastro e login. O foco aqui é o estudo sobre proteção de rotas, desenvolvimento backend e gerenciamento de banco de dados.

## ⚙️ Tecnologias utilizadas
- **Handlebars** - Para exibição de conteúdo na tela.<br>
- **Javascript** - Utilização em funcionalidades estáticas e comunicação com o backend.<br>
- **Node.js** - Construção do backend.<br>
- **MongoDB** - Banco de dados relacional para armazenamento de dados.

## ✅ Funcionalidades
- Cadastro de um novo usuário.
- Login de um usuário ja cadastrado.
- Exibição de erros padrões em um sistema de autenticação.

## ❓ Como utilizar

Clone esse repositório em sua máquina.<br>
```
git clone https://github.com/Leonardotav1/Agri-X.git
```

Após isso entre na pasta backend e rode o seguinte comando:
```
cd backend
nodemon dev
```

Pronto, o sistema já estará em funcionamento!!
